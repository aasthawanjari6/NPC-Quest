WHAT TO SAY IN YOUR VIVA

Interrupt → Save → Handle → Restore

The FSM identifies the current action, while the stack records the interrupted behavior. Because a stack follows Last In, First Out (LIFO), the most recently interrupted behavior is resumed first.

1. InterruptA sound pulls the NPC away from its patrol.
2. PUSHSave PATROL before switching to INVESTIGATE.
3. Nested interruptAn enemy appears; save INVESTIGATE before ATTACK.
4. POP + resumeFinish ATTACK, resume INVESTIGATE, then return to PATROL.
Academic note: This project demonstrates a PDA/pushdown-system abstraction of NPC behavior. It does not claim commercial game engines literally implement NPCs as PDAs. The simplified demo stores behavior contexts to make PUSH/POP and LIFO visible.
